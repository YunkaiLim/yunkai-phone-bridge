# Provenance

This public repository was prepared on 2026-09-30 as a sanitized source export from the owner's private Yunkai PhoneBridge working tree.

The export includes selected bridge source code, unit tests, example configuration, the optional local Control Center source, and the shared contract package needed by the bridge. It deliberately excludes machine/account bindings, the real tunnel ID, private runtime configuration, caches, local verification evidence, and binary tunnel clients.

Python packages listed in `requirements.txt` and Android Platform Tools are installed separately and are not vendored here; they remain under their own licenses.

The publication audit found no upstream repository URLs or third-party source-license headers in the selected bridge source files. The previous private-tree NOTICE named OpenAI; that notice was not carried forward because OpenAI's current terms assign Output rights to the customer/user as between the user and OpenAI, while third-party materials (if any) remain subject to their own rights. This note is not a warranty regarding separately installed dependencies.
